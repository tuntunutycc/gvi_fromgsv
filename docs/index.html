Green View Index, Chiang Mai University

Street-level greenery from Google Street View, and a Sentinel-2 model that estimates it on a 10 m grid. These pages use CartoDB, so they open without an API key. Each map has a layer control: turn a layer off to see the streets underneath.

  • Measured GVI at the 1,610 Street View samples
  • Sample locations and the pedestrian network
  • Predicted GVI for 20,455 campus squares

The numeric prediction table is campus_gvi_prediction.csv. Model tables are in the saved outputs of gvi_fromgsv.ipynb.
